NOVA CERULEO

Lanzador del juego para escritorio. Se descarga una sola vez: cada vez que lo abrís busca la última versión del juego y la instala sola.

Windows (10/11, 64 bits)
Linux (64 bits)
Cómo se usa
  1. Descomprimí el .zip en una carpeta (dejá juntos los dos archivos).
  2. Abrí NovaCeruleo.exe (en Linux, NovaCeruleo.x86_64). Windows puede avisar que el programa no está firmado: «Más información» → «Ejecutar de todas formas».
  3. El lanzador baja el juego (~26 MB la primera vez) y lo abre. Las actualizaciones se instalan solas al abrirlo.

¿Preferís no instalar nada? Jugá en el navegador: novaceruleo.org/3d
